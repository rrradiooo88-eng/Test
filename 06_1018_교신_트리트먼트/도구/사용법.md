# 도구 사용법

## md → docx → pdf, 그림 생성

2026년 10월 19일 · IF Studio

### 필요한 것

Node 18 이상과 npm 패키지 docx (8.x). `npm install docx`

Playwright와 Chromium. `npm install playwright` 뒤에 `npx playwright install chromium`

Python 3. 생성기는 표준 라이브러리만 쓴다.

LibreOffice (soffice). docx를 pdf로 바꿀 때만 필요하다.

나눔고딕 글꼴. 데비안·우분투는 `apt install fonts-nanum`. docx의 기본 글꼴이 NanumGothic이고 svg도 같은 글꼴을 먼저 찾는다. 없으면 맑은 고딕, Apple SD Gothic Neo, Noto Sans KR 순서로 떨어진다.

### md → docx

`node build_docx.js 입력.md 출력.docx`

A4, 여백 2cm, 본문 10.5pt 나눔고딕. md의 규칙은 README의 "시나리오 md 표기 규칙"과 같다. 전각 공백(U+3000)으로 시작하는 줄이 대사 단락이 된다.

### docx → pdf

`soffice --headless --convert-to pdf 출력.docx`

같은 폴더에 같은 이름의 pdf가 생긴다. 글꼴이 없으면 다른 글꼴로 대체되므로 먼저 나눔고딕을 설치한다.

### 그림 생성 (svg)

`python3 -I gen_red_panel.py 레드_패널_디자인.svg` 레드의 패널 세 상태.

`python3 -I gen_one_sheet.py 1호_표시등_디자인.svg` 1호의 표시등 문법과 몸.

`python3 -I gen_monitor.py 모니터_두안.svg` 17인치 모니터 두 안.

`python3 -I gen_bee.py 벌과수위_여섯장면.svg 벌과수위_개념도.svg` 인자가 둘이다.

`python3 -I gen_red_roles.py 레드_역할_씬별분석_v8.svg` v8 분석. 장면별 행동은 파일 안 SCENES 딕셔너리.

`python3 -I gen_red_roles_cmp.py 레드_역할_전후비교_v8v9.svg` v8과 v9 비교. V8, V9 딕셔너리와 V8_META, V9_META(교환·웃음·이름·판돈)를 고치면 그림과 오른쪽 합계, 아래 표가 같이 바뀐다. 시나리오 v9를 쓴 뒤 실제 행동을 세어 V9를 갱신하면 "계획"이 "결과"가 된다.

### svg → png

`node render_svg.js 입력.svg 출력.png 가로 세로`

가로 세로는 svg의 width, height와 같게 준다. 1.5배로 찍는다.

### 흐름

시나리오나 계획을 고친다 → md 저장 → build_docx.js로 docx → soffice로 pdf → 그림이 바뀌면 gen 파이썬으로 svg → render_svg.js로 png → 저장소에 같이 올린다.
